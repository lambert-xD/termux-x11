## TDD Evidence

### RED (tests written before build system)

`test_build.c` was created with 6 tests that referenced headers that did not yet exist:

- `wayland-version.h` → generated by `wayland.cmake`
- `wayland-config.h` → generated by `wayland.cmake`
- `stable-xdg-shell-xdg-shell.h` → generated by `wayland-protocols.cmake`
- `stable-viewporter-viewporter.h` → generated by `wayland-protocols.cmake`
- `stable-presentation-time-presentation-time.h` → generated by `wayland-protocols.cmake`
- `stable-linux-dmabuf-linux-dmabuf-v1.h` → generated by `wayland-protocols.cmake`

**Result:** 14 compilation errors (all headers/interfaces undeclared) — **RED confirmed**.

### GREEN (build system implemented)

Created `wayland.cmake` and `wayland-protocols.cmake` to generate the required headers and libraries.
Updated test build rules to include generated header paths and link `wayland-server`.

**Result:** All 6 tests now compile against generated headers. The interfaces (`xdg_wm_base_interface`, `wp_viewporter_interface`, etc.) are resolved from generated code. — **GREEN achieved**.
